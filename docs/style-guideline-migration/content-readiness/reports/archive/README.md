# Entrega inicial archivada

`initial-1.0.0/` conserva los 24 archivos copiados antes de editar la corrección:
informes JSON/Markdown, TAP de las 35 pruebas, huellas, documentación, entradas y
código del auditor 1.0.0. `archive-manifest.json` identifica cada copia por SHA-256.

Las copias de documentación conservan sus bytes y enlaces relativos originales;
esos enlaces se interpretan desde la ubicación original de la entrega. Para
navegación actual, usar el REPORT y el contrato del directorio de datos principal.

No se copió ni se refrescó el árbol original de snapshots. El manifiesto del
archivo también conserva las huellas de los 109 datos congelados y del archivo
de las 35 pruebas originales. El verificador contrasta esos archivos y cada copia
archivada antes y después de ejecutar la corrección.

La entrega corregida está en `../correction-1.0.1/`; los paths estándar
`../offline/`, `../live/` y `../reproducibility.json` contienen el resultado vigente.

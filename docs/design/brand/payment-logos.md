## What this means for PR #15 (22 px, grey transfer + colored marks)
- **Apple Pay in black does not comply.** The only allowed artwork is Apple's white mark with an outline rule.
- **Google Pay:** use Google's SVG as-is (full color with outline).
- **Visa:** must be Visa Blue (full-color screen).
- **Size parity:** Visa, Mastercard, Apple and Google all require equal size and prominence. Keep the row at one height.
- **Only show marks for methods that are actually offered:** Mastercard FAQ, Apple (canMakePayments / supported devices), Google (payment option). This matches the existing LOGO-01 rule.
- **Open items:** Mastercard page blocked (403); recheck the digital Symbol minimum in a browser. Mercado Pago minimum size is only in images on the official page or in the kit. PayPal has no current official acceptance-mark guideline online. Ask PayPal MX or use the older 37×23 px value, which means 23 px or more.

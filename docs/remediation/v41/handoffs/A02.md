## Implemented locally

- One stable selected variant ID travels from common card to quick view, PDP, add/buy, and back. ID wins over the retained legacy index argument. A missing ID or nonexistent option combination stays unavailable; another colour/size is never substituted. Quick view resolves the latest catalog by ID before purchase, including after variant ordering changes.
- Storefront first-page and continuation queries request exact `selectedOptions { name value }` and associated `image { url(...) }`. GraphQL, bundled snapshot and Firestore product mappers retain supported option/image metadata. Firestore accepts A03's options object and image URL list, defaults absent legacy fields, and rejects malformed metadata without replacing the last good cache.
- Schema **9 → 10** adds `cached_variants.selected_options` and `image_urls` with empty defaults. Existing catalog, bag and identity rows survive; only the sync cursor is reset to request a complete online metadata backfill. Database cold reopening preserves options, imagery, price, compare-at and stock. No live migration was executed.
- Option controls use exact source names and values. Named multi-dimensional selectors retain the other selected values and represent missing/exhausted combinations. Legacy titles remain neutral text choices, never fabricated colour metadata. Product-level inferred colours are no longer appended to card titles.
- Card price, comparison, discount, stock and photography come from the same selected variant. A null compare-at never falls through to another variant's price. Photography is explicitly associated; product gallery fallback is allowed only for a single-variant product. Missing multi-variant image membership shows the existing image fallback.
- Supplied heart SVGs render within transparent, keyboard-accessible 48px targets. Saved gold stays inside the silhouette. Photo-ground contrast is explicit in dark mode. `AGOTADO` is a compact, static black label with white text at the lower photo edge; no image washout or central seal remains.
- Ordinary cards open quick view. Optional featured mode opens PDP directly. Quick view has X/Escape and independent favorite/option controls; image and Ver producto close the layer before entering PDP, preserving selection. Add waits for the real existing store result, guards repeated taps, retains errors/selection, and confirms in place. Comprar ahora preserves other bag lines and opens the bag only after successful add.
- PDP continuation is Descripción → Otras formas de comprar → Envíos → Cambios y devoluciones, with source-dependent sections hidden until approved content is attached. WhatsApp appears only inside the opened purchase-method accordion. The contextual request retains product/variant/price and attribution code, without inventing deposit, timing, reservation or payment terms.
- Distinct recommendation sets appear as Relacionados → Más de la marca → Vistos hace un momento. Related uses observed canonical category/silhouette membership; brand uses canonical brand; history uses actual session order. Sets exclude the current product, deduplicate IDs, retain up to 40 real items, omit empty sets, build visible items lazily, expose manual navigation, and open the exact same set in a full page. No products are repeated to fill a count. The existing A00-owned session-history store remains capped at 12.
- Zoom has enlarge/reduce/reset, scale text, real multi-photo navigation, keyboard/Escape and focus return. Gallery selection is retained after exit. Pinch complements the explicit controls.
- Enlarged labels wrap without scaleDown. Caption/option/footer measurements protect text and reduce the contained photo area when a fixed card cell is short. Full-set headings grow at enlarged text. System reduced motion remains respected; buttons use A01's static Glass surface and opaque fallback.

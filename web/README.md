# Monetta current UI atlas

This is a Vercel-ready static Vite viewer for the current Monetta screen SVGs. It intentionally stays focused on the UI atlas: choose a board, fit it to the canvas, zoom and pan through the screen compositions.

## Local

```bash
npm install
npm run dev
```

## Vercel

The repository root already contains `vercel.json`. Import the repository into Vercel and deploy with the default settings; the config installs and builds the `web/` app and serves `web/dist`.
